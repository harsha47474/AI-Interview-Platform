# Colloquium — AI Interview Platform

An AI-powered mock interview platform with real-time speech recognition, AI evaluation, credits system, and detailed performance reports.

---

## 🚀 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 19 + Vite + Tailwind CSS v4 |
| Backend | Node.js + Express 5 |
| Database | MongoDB (Mongoose) |
| Auth | Firebase Google OAuth + JWT cookies |
| AI | OpenRouter (LLM API) |
| State | Redux Toolkit |

## ⚙️ Local Development Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Interview-Platform.git
cd AI-Interview-Platform
```

### 2. Set up the Server

```bash
cd server
cp .env.example .env
# Edit .env and fill in your MongoDB URL, JWT secret, and API keys
npm install
npm run dev
```

### 3. Set up the Client

```bash
cd client
cp .env.example .env
# Edit .env and fill in your Firebase API key
npm install
npm run dev
```

The client will run at **http://localhost:5173** and the API at **http://localhost:3000**.

## 🌐 Production Deployment

### Option A: Full-Stack on a single server (Render / Railway / VPS)

1. **Build the client:**
   ```bash
   cd client
   VITE_API_URL=https://your-api-url.com npm run build
   ```

2. **Configure the server `.env`:**
   ```env
   NODE_ENV=production
   PORT=3000
   MONGODB_URL=...
   JWT_SECRET=...
   OPENROUTER_API_KEY=...
   CLIENT_ORIGIN=https://your-frontend-url.com
   ```

3. **Start the server** (serves the React build automatically):
   ```bash
   cd server
   npm start
   ```

### Option B: Separate Deployments (Vercel frontend + Render backend)

**Frontend (Vercel):**
- Set `VITE_API_URL=https://your-backend.onrender.com` in Vercel's environment variables
- Deploy `client/` as a Vite project

**Backend (Render / Railway):**
- Set all server `.env` variables in your hosting dashboard
- Set `CLIENT_ORIGIN=https://your-frontend.vercel.app`
- Set `NODE_ENV=production`
- Start command: `npm start`

## 🔑 Environment Variables Reference

### Server (`server/.env`)

| Variable | Description |
|---|---|
| `PORT` | Server port (default: 3000) |
| `MONGODB_URL` | MongoDB connection string |
| `JWT_SECRET` | Secret for JWT signing |
| `OPENROUTER_API_KEY` | OpenRouter LLM API key |
| `CLIENT_ORIGIN` | Allowed CORS origin(s), comma-separated |
| `NODE_ENV` | `development` or `production` |

### Client (`client/.env`)

| Variable | Description |
|---|---|
| `VITE_FIREBASE_APIKEY` | Firebase Web API key |
| `VITE_API_URL` | Backend API base URL |

## ✨ Features

- 🤖 **AI Interview** — 5 progressive questions generated by LLM based on your role, experience, and resume
- 🎤 **Speech Recognition** — Real-time answer transcription via Web Speech API
- 📊 **Detailed Reports** — Per-question scoring on Confidence, Communication & Correctness
- 💰 **Credits System** — Simulated payment gateway (UPI / Card / NetBanking) to purchase interview credits
- 📈 **Interview History** — Browse all past sessions with scores and feedback
- 🔐 **Google OAuth** — One-click sign-in via Firebase
